# Future ZONT integration

This directory is reserved for the future native Home Assistant integration.

No integration code is intentionally published yet. The current controller is not used as the protocol baseline for the new implementation.

Development starts after the replacement ZONT controller is installed and its local interfaces are verified.

Planned order:

1. local discovery and protocol research;
2. read-only client;
3. coordinator and diagnostics;
4. Home Assistant entities;
5. verified local write/control operations;
6. packaging and HACS readiness.
